Optional prebuilt hwspoof.exe (no Rust compile required)

1. Download the official x64 release from https://hwidspoof.net or GitHub releases.
2. Rename or copy the binary to:  HWIDTool\bin\hwspoof.exe
3. Run HWIDTool\Run_As_Admin.bat or run_windows.bat

run_hwid.bat checks this folder before invoking cargo. Verify SHA-256 from the official site.
